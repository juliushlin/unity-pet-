# 和小月一起制作游戏

## 聊天与互动

小月脚下有一条带铅笔图标的按钮。点一下展开暖白、绯红聊天框，再点一下收起。展开时小月低头看聊天区，收起后抬头。聊天记录和输入区都比旧版紧凑。Unity 菜单 **小月 → 协作窗口** 也使用同样的操作。

点击角色触发可爱动作，拖动移动桌面窗口；右键菜单可以选择动作或退出。取消了旧版 3D 模型及转身操作。平时只有固定待机，180 秒没有鼠标键盘输入会睡眠，有操作后醒来。

输入要求后点击发送才开始执行。正在执行时等待状态更新；停止按钮会结束当前任务，但不会撤销已经完成的项目修改。

## 需求示例

```text
小月，先确认连接的是当前 Unity 项目，再帮我做一个简单的第三人称移动场景。
使用现有输入系统，保留其他场景，完成后运行并检查错误。
```

```text
主人想让跳跃轻盈一点。请修改相关参数，完成后验证，其他行为保持不变。
```

```text
先只读检查当前场景、对象和编译错误，不修改文件。
```

任务会把当前项目路径、近期对话和本次要求交给 Codex。复杂制作可能需要较长时间，权限不足或工具失败应以实际回复为准。制作前建议提交 Git 检查点。

## 全局跟随 Unity 启动

本机已启用 Tools/watch-unity.ps1 后台检测器。登录后检测器自动运行，约每三秒检查一次 Unity 编辑器。打开任意项目时，它会给小月传入该项目路径和编辑器进程 ID。每个编辑器窗口拥有自己的小月，关闭编辑器后对应的小月退出。

当前用户的“启动”文件夹内，Xiaoyue Unity Companion.lnk 用于唤起检测器。移除这个快捷方式即可取消登录启动。小月本体和 Tools 目录需要保留在原位置。

其他项目要让 Codex 实际读取和修改 Unity 场景，仍需在该项目安装并启动 Coplay Unity MCP 或 Unity Pipeline。自动显示桌宠与项目内工具连接分别需要各自就绪。

## Unity 前台显示与出场动画

角色头顶不再显示名字。桌面小月第一次显示时，先在屏幕中央探出半个头，再跳出来，最后以跳步与摇摆动作移动到右侧，整个出场约 3.6 秒。铅笔入口在出场完成后显示。

绑定的 Unity 编辑器处于前台时显示小月。切到其他程序、切到另一个 Unity 项目或最小化时隐藏，恢复该编辑器后继续显示。点击小月自身的聊天框时保持显示，以便输入。关闭对应编辑器后退出。

本机已验证构建成功、对应编辑器前台显示、切到浏览器时隐藏。出场动画使用现有插画的裁切、变形与补间动作。

## 出场动作第二版

出场改用专用的 4 列 × 3 行透明图集，共 12 个姿势。顺序为双手扒住开口边缘露出半个头、抬头、双臂撑起身体、跃出、落地、朝右转身，以及六帧侧面跑步循环。整段约 5.4 秒，跑步阶段约 2.1 秒，到右侧后恢复原待机立绘。

图集位于 Assets/Resources/XiaoyueEntrance.png，由内置图像生成工具根据原角色图集制作。生成要求包括同一角色与绘画风格、透明背景、双手明确抓住边缘，以及侧面跑步的交替步态和反向摆臂。播放逻辑位于 XiaoyueEntranceAnimation.cs。修改后需重新构建桌面程序。
