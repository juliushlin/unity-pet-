# 和小月一起制作游戏

## 聊天与互动

小月脚下有一条带铅笔图标的按钮。点一下展开暖白、绯红聊天框，再点一下收起。展开时小月低头看聊天区，收起后抬头。聊天记录和输入区都比旧版紧凑。Unity 菜单 **小月 → 协作窗口** 也使用同样的操作。

点击角色触发可爱动作，拖动移动桌面窗口；右键菜单可以选择动作或退出。取消了旧版 3D 模型及转身操作。平时只有固定待机，180 秒没有鼠标键盘输入会睡眠，有操作后醒来。

输入要求后点击发送才开始执行。正在执行时等待状态更新；停止按钮会结束当前任务，但不会撤销已经完成的项目修改。

## 需求示例

```text
小月，先确认连接的是当前 Unity 项目，再帮我做一个简单的第三人称移动场景。
使用现有输入系统，保留其他场景，完成后运行并检查错误。
```

```text
主人想让跳跃轻盈一点。请修改相关参数，完成后验证，其他行为保持不变。
```

```text
先只读检查当前场景、对象和编译错误，不修改文件。
```

任务会把当前项目路径、近期对话和本次要求交给 Codex。复杂制作可能需要较长时间，权限不足或工具失败应以实际回复为准。制作前建议提交 Git 检查点。
